# 企业知识库系统 — 产品介绍素材

## 一句话定位
上传企业资料，10 分钟内获得可追溯、可验证的 AI 知识助手。答案引用原文，权限自动同步。

## 核心价值
- **统一知识管理**：5 大知识空间、128 份文档、156 个可问答知识，一站式管理
- **可信 AI 问答**：每个答案引用原文、量化置信度，冲突知识自动识别
- **多渠道接入**：飞书/钉钉/企业微信/官网客服/API，5 种渠道会话内即用
- **应用生态**：8 款智能应用（飞书问答插件、企业微信知识助手、官网客服组件等），一键安装

## 系统架构
- 前端：React 19 + Vite + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion
- 后端：Fastify + better-sqlite3 + Zod 校验
- 共享包：TS 类型 + Zod Schema（前后端单一来源）
- 测试：165+ inject 测试，:memory: 隔离
- VITE_USE_MOCK 切换：默认走 mock 演示模式，置 0 走真实后端 API

## 功能模块

### 1. 工作台 Dashboard
- 今日待办（3 项新手引导 + 用户任务）
- 运营趋势图表（问答量/认可率/活跃用户/接入渠道）
- 智能助手小知面板（左侧独立滚动）

### 2. 知识管理
- 知识空间（5 个：产品知识/销售知识/客服知识/技术文档/运营规范）
- 文档管理（128 份，支持版本/状态/权限/来源/最后修改时间）
- 数据来源（企业网盘/飞书文档/本地上传等连接器）
- 知识地图（多维度视图：图/列表/分类树 + 分类/类型/状态/作者维度重组）

### 3. AI 智能助手
- 助手管理（2 个助手：企业知识助手/销售知识助手）
- 对话会话（10 个会话，飞书/企微/钉钉/API/网站多渠道来源）
- 指令管理（7 条指令，4 条系统预置 + 3 条自定义，支持版本发布/回滚）

### 4. 应用中心
- 8 款应用（问答助手/客户服务/开发集成/运营分析/文档协同/安全集成）
- 应用卡片多样展示（featured 大卡/standard 卡/compact 小卡）
- 已安装 3 款：企业微信知识助手、自定义 API、单点登录 SSO

### 5. 集成管理
- 4 大渠道集成（飞书文档/企业微信/钉钉/单点登录 SSO）
- 集成状态（2 已连接、1 未连接、1 已停用）
- 配置面板（作用域/渠道映射/异常降级）

### 6. 运营分析
- 使用趋势（问答量/认可率/活跃用户/接入渠道）
- 知识治理（过期文档/冲突版本/缺失知识）
- 反馈闭环（用户反馈→问题→改进）

### 7. 安全与权限
- 6 级角色权限（管理员→知识管理员→空间管理员→文档审核员→助手运营员→普通成员）
- SSO 单点登录
- 审计日志
- API 密钥管理

### 8. API 与开发
- RESTful API（~50 端点）
- 核心域（25 端点）：认证/组织/空间/文档/连接器/知识地图/搜索
- AI 域（15 端点）：助手/对话/指令/实时 QA
- 应用与集成域（10 端点）：应用/集成/API Key/自定义 API/Webhook
